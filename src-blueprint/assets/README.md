## `src-new/assets/`

Recursos estáticos **no versionados por feature**.

### Qué va aquí
- Imágenes, íconos, fuentes, placeholders.
- Archivos que no dependen de lógica de negocio.

### Qué NO va aquí
- Assets específicos de una feature (preferir `src-new/features/<feature>/components` si están acoplados al módulo).
